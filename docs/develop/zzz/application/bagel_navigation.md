# 贝果导航与连续路点

导航使用固定小地图位置和独立镜头方向控制移动。角色箭头仅用于显示和诊断。观测机制见[位置与朝向](bagel_heading_observation.md)，路线和编辑操作见[流程开发工具](bagel_flow_editor.md)。

## 适用范围

前台键盘支持镜头相对的八方向移动，即W、A、S、D及相邻两键组合。后台虚拟手柄的方向接口会覆盖整根摇杆，不能按键盘方式叠加方向；该分支继续使用前进与转镜头，不启用本节的八方向冲刺。

距离均为标准201×201小地图中的地图像素，不是屏幕上的角色移动距离。固定底图的有效遮罩不表示道路可通行。导航不提供自动绕障或遇敌恢复。

## 连续执行普通路点

普通`move`的路点默认`stop: true`。只有同时满足以下条件，执行器才把相邻步骤交给同一个导航操作：

- 步骤在原流程中连续，且均被本次执行选中。
- 每步均为单路点的普通坐标移动，导航参数完全相同。
- 前一步明确设置`stop: false`。
- 没有提前刹车配置、容器接近、其他动作或未选步骤隔开。

到达判断仍使用当前真实位置、原到达范围和原越点范围。确认到点后，执行器发送原步骤的结束、开始事件，并在同一有效观测上更新下一段移动键，不提前切弯。

每步保留独立超时、动作预算和失败归属。单独试跑一个不停步路点时，该点仍是本次导航终点，到点必须收键。参数不同或选择不连续时，不补执行中间步骤。

C发布流程将回长廊至楼角的普通移动连续执行，箱前接近点仍独立停步。具体坐标、范围及停步标志以[发布流程](../../../../assets/game_data/bagel/janus_high_c/flow.yml)为准。

## 路段跟随与走偏恢复

普通坐标移动在距离目标超过10px时使用路径跟随。程序把当前位置投影到当前路段，再沿本段前视4px，得到纠偏目标；前视点不会越过本段终点。

每次有效观测都重新选择最近的八方向组合。镜头与移动键共同朝前视点纠偏，镜头只补所选组合的角度残差，不要求先转到W朝向。行进中的转向输入保留反馈窗口，移动键仍可依据新的位置和镜头更新；这些反馈不用于停车转幅标定。

横向偏差超过2px时：

1. 释放移动键并丢弃旧转向反馈。
2. 取得动作后的新位置和镜头方向。
3. 朝当前路段最近点短按移动键0.08秒，结束后收键。
4. 等待新截图，再判断是否仍需修正。
5. 横偏回到1px以内后，恢复连续跟随。

这一恢复分支不停车对齐镜头，不放宽原到达范围。短步仍受动作次数、导航超时和持续无位移保护约束。位置或镜头未知时不执行纠偏。

## 近点减速与到达

普通路点进入最后10px后，先释放持续移动键，再等待镜头反馈和执行短步，避免在反馈等待期间越过转角。短步前按当前镜头选择移动组合；方向允许误差由原到达范围与当前距离计算，上限30°，不扩大到达范围。

| 场景 | 移动方式 |
| --- | --- |
| 连续执行且不停步的中间点 | 短按0.12秒，等待0.05秒后重新观察；到点后立即接续下一段 |
| 普通终点 | 沿用普通短步和停步要求 |
| 容器碎步接近 | 每次短按0.08秒，以当前目标提示作为完成条件 |
| 显式提前刹车点 | 先停稳，再用新截图继续当前步骤；松键本身不代表到达 |

所有时长都是输入和观察参数，不是保证的角色位移。近点对齐仍可能停车，连续路点也不等于角色全程保持相同速度。

最终容器接近只使用本次确已执行的相邻移动点作为进场方向参照。单独试跑接近步骤时，不推断尚未执行的路线。容器停稳和交互预算见[容器恢复](bagel_container_recovery.md)。

## 冲刺起步

前台键盘只在以下条件全部成立时尝试冲刺：

- 当前路段剩余距离至少10px，且该路点尚未尝试过冲刺。
- 当前位置和路段起点有效，移动组合已经按住，没有待确认的镜头转向。
- 横偏不超过1px，按键组合与目标方向的角差不超过7°。
- 0.5秒内已观测到至少2px位移，实际位移方向与目标方向相差不超过12°。

满足条件后，程序保持移动组合，短按当前配置的闪避键0.08秒，并在正常结束或异常时释放。每段最多尝试一次；暂停、收键和短步不会清除该记录。这里的冲刺只定义输入行为，不假定固定加速或位移距离。

普通坐标段已触发冲刺、尚未到达且进入最后10px时，先收键0.15秒，再用新位置继续判断。容器接近段也只有在满足距离和方向条件时才可能触发，不能把“靠近箱子”笼统视为允许冲刺。

## 镜头反馈与转幅估计

图像角度以顺时针为正，控制器角度在入口转换一次。待确认转向记录实际下发的限幅命令、输入时刻、源镜头角和位置，不以名义目标角代替实际命令。

行进微调的名义命令上限为30°，停车命令上限为90°。转向后先等待新帧；最终停车对齐和标定要求连续两帧镜头差不超过2°、间隔至少0.08秒。已标定的大角度中间修正只有满足反馈条件才可提前继续，不能因此省略最终稳定核对。

[BagelTurnCompensator](../../../../src/zzz_od/application/bagel/bagel_turn_compensation.py)在同一任务、同输入条件下跨局保留比例，不写回公共`turn_dx`配置。输入模式、基础换算或窗口尺寸改变时重新估计。

可靠样本要求停止运动后取得独立停车反馈、距离目标超过10px、位置变化不超过2px，且命令与观测同向并满足幅度要求。至少8个可靠样本、最近24个样本的相对中位绝对偏差不超过0.15时，才建立正式比例，范围为0.5—3。

正式比例尚未建立时，连续3个可靠反馈一致显示欠转或过转，才小步调整临时比例；单次变化不超过0.1，临时上限1.5，仍不标记为已完成标定。行进反馈、定位或HUD中断、受击后的明显位移不作为可靠停车样本。

## 未知、停止与输入释放

镜头未知时立即收键，最多等待2秒；不盲转探测，也不用角色角、候选角或历史角补值。转向没有响应或反馈超时同样停止。

定位和HUD的重读规则见[出生识别与导航](bagel.md#出生识别与导航)。普通移动、电子保险箱及机械保险箱导航保留持续无位移保护：位置连续3秒未离开2px范围时停止并报告失败。计时在收键或暂停后清除，不能用于判断已避开敌人。

[BagelMovement](../../../../src/zzz_od/application/bagel/bagel_movement.py)记录实际输入后端与物理键。换方向时保留共同键；短步结束、失焦、暂停、异常及导航结束时释放已持有的键。一个键释放异常时仍尝试释放其余键。正式运行需要控制端互斥，这个类不提供跨进程输入锁。

## 已知限制

当前仍使用近点镜头对齐和固定短步，没有实现按实际速度调整步长，也没有实现动态制动距离。短暂停顿、惯性过冲、受击和障碍仍可能导致失败。后台八方向、不同角色和不同输入条件的完整效果尚未验证；最终同版各路线20次的成功率验收尚未完成。

位置观测未出现某个时长的近静止片段，不等于物理全程不停；单次通过也不能代表长期成功率。
